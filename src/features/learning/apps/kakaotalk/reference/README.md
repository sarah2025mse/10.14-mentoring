# 카카오톡 캡처 (참고용)

이 폴더의 이미지는 연습용 카카오톡 화면을 실제와 비슷하게 맞추기 위한 참고 자료예요.
실제 이름, 대화, 사진이 들어 있어서 **Git 기록에는 넣지 않아요** (`.gitignore` 참고).
코드에서 이 이미지를 불러오지 않아요. 화면은 모두 도형과 아이콘으로 직접 그려요.

| 파일 | 내용 |
|---|---|
| 친구 탭.jpg | 친구 탭 (위쪽 '소식'이 골라진 상태) |
| 친구 탭_업데이트 전후.png | 친구 탭 업데이트 전과 후 비교. 레슨은 '업데이트 후'의 '친구' 화면을 따라요 |
| 채팅방 목록 탭.jpg | 채팅 탭 (채팅방 목록) |
| 채팅창_기본.jpg | 채팅방 기본 모습 |
| 채팅창_메시지 입력.jpg | 입력창을 눌러 키보드가 올라온 모습 (문자 보내기 레슨 참고) |
| 채팅창_이모티콘 입력.jpg | 이모티콘 판 |
| 채팅창_사진전송.jpg | + 를 눌렀을 때 올라오는 판 (최근 사진, 사진, 송금, 파일, 선물하기, 통화) |
| 채팅창_사진 전송.jpg | 위 판에서 최근 사진 하나를 고른 모습 ("1 전송") |
| 사진 선택 화면.png | + → '사진'을 눌렀을 때 나오는 전체 사진 화면 |
| 채팅창.jpg | 채팅방 (화면 속 화면 캡처 포함) |
| 더보기 탭.jpg | 이름과 달리 채팅방 오른쪽 위 ☰ 를 누르면 나오는 '채팅방 서랍' 화면 |
